Class Room

A Room is a location the player can be in. Rooms may be linked together directly, or via Doors, and traversed between using directional keywords e.g. north, west, s, up, etc.

Rooms may contain Items. If they're holdable, they'll automatically be included in the description. Rooms (indeed, all containers) can also "hide" items, such that the Room must be examined before the items can be discovered and interacted with by the player.

Rooms are constructed using a builder.

const kitchen = new Room.Builder("kitchen")
  .withDescription("The kitchen is well-stocked and homely.")
  .hasItems(table, oven, sink)
  .hidesItems(cat, book, knife)
  .build();
